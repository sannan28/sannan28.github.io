              提交代码遇到的问题：
	         idea中git merge 和rebase区别
		     先来说一下merge，merge是只两个及两个以上的commit对当前同一个分支的代码做了修改，所以两个commit会分别和分支最开始的未修改的代码做比较，如果两个commit其中有一个提交和原来代码没有变化，那就会直接合并，如果两个commit对比后都有变化，那就需要手动合并，解决冲突。
		     在来说一下rebase，rebase在当前分支作修改提交的时候，会把其他commit的都撤销，然后先进行自己的commit，然后在添加别的commit。所以如果出现冲突可能要修改多次。

       step1: 首先是需要准备好 nacos docker镜像的源码 链接地址：https://nacos.io/zh-cn/docs/quick-start-docker.html
                可以通过git进行下载，因为我的虚拟机里没有git 所以我是安装在本地 然后使用scp命令上传到我的虚拟机内的

                 sudo scp -r /Users/lishengnan/docker/nacos-docker root@47.100.33.56:/root/dockerfile
       step2: 然后准备需要使用的nacos-server版本 这里我使用的是nacos-server-2.0.4
                  链接地址：https://github.com/alibaba/nacos/releases/download/2.0.4/nacos-server-2.0.4.tar.gz
                  同样的也需要把这个包上传到ecs的home目录下 sudo scp -r /Users/lishengnan/docker/nacos-server-2.0.4.tar.gz root@47.100.33.56:/home        
                说明:上传到home 并不是固定的，之所以采用从本地上传到ecs中 主要是网络状况不好 不然可以直接使用wget命令 或者curl命令下载也是可以的
       step3: 准备好需要使用的工具后 需要更改下 /nacos-docker/build/Dockerfile文件的内容 由于已经准备好 nacos-server包了 所以需要修改
                 1.ARG NACOS_VERSION=2.0.4
                 2.
                 RUN set -x \
                     && yum update -y \
                     && yum install -y java-1.8.0-openjdk java-1.8.0-openjdk-devel iputils nc vim libcurl \
                     && yum clean all
                 RUN tar -xzvf /home/nacos-server-2.0.4.tar.gz -C /home \
                     && rm -rf /home/nacos-server-2.0.4.tar.gz /home/nacos/bin/* /home/nacos/conf/*.properties /home/nacos/conf/*.example /home/nacos/conf/nacos-mysql.sql \
                     && ln -snf /usr/share/zoneinfo/$TIME_ZONE /etc/localtime && echo $TIME_ZONE > /etc/timezone

       step4: 就可以在build文件夹下执行构建的命令了
                 docker build -t nacos/nacos-server-2.0.4 .
